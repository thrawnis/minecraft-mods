# Minecraft Mods

A collection of Minecraft **Java Edition** mods, resource (texture) packs and maps. Mods are in `mods/`, maps and worlds in `worlds/`, and resource packs in `texture-packs/`. Each project has its own folder, and its README explains how to install and use it.
